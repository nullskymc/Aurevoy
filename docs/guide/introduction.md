# 概览

Aurevoy 是跑在你电脑上的**个人 AI Agent**。你给出一个目标，它会收集上下文、规划步骤、调用工具，并在本机持续执行，直到任务完成、失败，或被你停止。

它更接近「会动手的协作者」，而不是只回文字建议的聊天框。

## 适合做什么

- **代码与仓库**：解释结构、改功能、修 bug、补测试与文档  
- **本地文件**：转换格式、整理目录、按规则批量处理  
- **调研与写作**：检索网页或知识库，输出清单、纪要、报告草稿  
- **重复流程**：配合 Skill，把「每次都要说的一套做法」固定下来  

## 它如何工作（用户视角）

1. 你在输入框描述目标（可附带文件、绑定项目目录）  
2. 本机引擎调用你配置的模型，并决定使用哪些工具  
3. 执行过程在对话中以状态流呈现；需要时会请求你**审批**或**补充信息**  
4. 结果以 Markdown、文件改动或产物形式交付；你可审阅、纠正、重试  

```
你（目标） → 本机引擎 + 模型 → 工具 / Skill / MCP
                ↓
         对话、工作台、可选审批
```

## 和「普通 AI 对话」的差别

| | 普通对话 | Aurevoy |
|---|---|---|
| 主要产出 | 建议与文案 | 可在本机读写文件、跑工具、交付结果 |
| 上下文 | 你粘贴什么算什么 | 可绑定项目、记忆、知识库 |
| 控制 | 继续追问 | 停止、审批、编辑重试、分支、预算 |
| 数据默认位置 | 取决于云端产品 | 任务与记忆默认在本地；模型请求发往你配置的 Provider |

## 你需要准备什么

- **macOS 应用**（当前优先支持）  
- **自己的模型 API Key**（OpenAI 兼容、Anthropic 等）  
- 可选：本地 Embedding（知识库语义检索）、搜索后端、MCP 服务器  

Aurevoy **不**托管你的账号体系，也**不**把「假能力」做成看起来成功的演示。外部服务挂了或未配置时，应看到明确失败或降级说明。

# 界面与对话

界面围绕一条主线：**目标 → 执行状态 → 可审阅的结果**。过程细节默认收起，避免把「运行日志」当成主视觉。

## 布局

```
┌──────────────┬────────────────────────────┬──────────────────┐
│ 侧栏          │ 对话流                      │ 工作台（可选）     │
│ 历史与入口     │ + 底部输入框                 │ 文件树与预览       │
└──────────────┴────────────────────────────┴──────────────────┘
```

窄屏下侧栏可收起，工作台可关闭，保证主对话可读。

## 侧栏

| 入口 | 用途 |
|---|---|
| **新对话** | 开始一条新任务（建议一事一对话） |
| **对话列表** | 历史任务；可搜索、按状态筛选 |
| **项目** | 导入 / 切换工作区 |
| **Skill** | 浏览、启停、安装 Skill |
| **记忆** | 长期记忆条目 |
| **设置** | 模型、权限、搜索、知识库、MCP、数据等 |
| **搜索** | 在对话等范围内查找 |

列表状态与产品文案一致：等待中、正在规划、执行中、等待确认、已完成、失败、已取消等。

## 对话区在展示什么

| 阶段 | 你看到的 |
|---|---|
| **空态** | 引导与建议目标，大输入框 |
| **运行中** | 单行或精简状态流（当前阶段 / 工具），不默认展开整棵工具树 |
| **等待确认** | 审批卡贴在输入框上方；追问出现在对话流 |
| **完成后** | 可展开的扁平活动列表；交付为左对齐 Markdown |
| **失败** | 失败原因与分类提示，便于对照 [故障排查](./troubleshooting) |

用户消息靠右；Agent 交付不加装饰性头像条，方便直接读内容与复制代码。

## 输入框

| 能力 | 说明 |
|---|---|
| 文本目标 | 描述要完成的事，见 [如何写目标](./prompting) |
| 模型 | 在已启用模型间切换 |
| 推理深度 | 对支持扩展推理的模型循环切换 |
| 附件 | 图片 / 文件作为多模态输入 |
| `/` | Skill 与斜杠命令（如 `/compact`） |
| 发送 | 引擎在线且已配置模型时可用 |
| 停止 | 执行中中止当前任务 |

未配置模型或引擎离线时，发送禁用并显示原因——这是预期行为，不是坏掉。

## 工作台与输出

- **工作台**：浏览项目文件、打开预览 / 源码、查看对话产物  
- **输出区**：与工作台在布局上互斥，避免挡住主对话  

绑定项目后，从对话点到路径类结果时，适合在工作台核对。详见 [项目与工作台](./projects)。

## 工作模式（设置）

| 模式 | 倾向 |
|---|---|
| **适用于编程** | 默认保留更多工具与执行细节 |
| **适用于日常工作** | 默认收起工具细节，优先结论 |

只影响呈现密度，不改变模型本身。可按任务类型切换。

# 快速开始

从下载到发出第一个可用目标，按顺序做完下面四步即可。

## 1. 安装应用

1. 打开 [GitHub Releases](https://github.com/nullskymc/Aurevoy/releases)  
2. 下载最新 **macOS DMG**，将 Aurevoy 拖入「应用程序」  
3. 启动应用  

若系统提示无法验证开发者：仅从上述官方 Releases 下载，然后在 **系统设置 → 隐私与安全性** 中允许打开，或对应用图标使用 **右键 → 打开**。正式签名与自动更新仍在推进中。

启动后，输入区附近应显示引擎状态。**本地引擎在线** 表示本机 Agent 进程可用。若长时间离线，完全退出后重开；仍失败见 [故障排查](./troubleshooting)。

## 2. 配置模型

Aurevoy 不内置云端账号。你需要接入自己的 Provider。

1. 打开侧栏 **设置**  
2. 在 **提供商** 中选择类型（如 OpenAI 兼容、Anthropic）  
3. 填写 **API Key**；使用中转或本地网关时填写 **Base URL**  
4. 在 **模型** 中启用至少一个模型  
5. 返回对话页，在输入区模型选择器里选中它  

密钥保存在本机设置存储，不会进入 git 仓库。

::: tip 本地模型
若使用 Ollama 等 OpenAI 兼容接口：Base URL 指向本机（例如 `http://127.0.0.1:11434/v1`），模型名与本地一致，Key 按服务要求填写或留空。
:::

配置正确后，输入框应允许发送。若仍提示「未配置 LLM」，检查是否**启用了模型**且 Provider 已有 Key。

## 3. （推荐）选择工作位置

改代码或批量动文件时，先让 Agent 知道「在哪干活」：

1. 侧栏打开 **项目** → **导入项目**  
2. 选择本地文件夹（仓库根目录或你要处理的目录）  
3. 在该项目下 **新对话**  

未绑定项目也可以聊（独立对话），适合一次性调研或写作。文件类任务绑定项目后边界更清晰，也便于在工作台预览改动。详见 [项目与工作台](./projects)。

## 4. 发出第一个目标

在输入框用自然语言描述**结果**，而不是逐步菜单操作。第一次建议选范围小、可验证的事。

试试下面任一示例（按你的路径改一下）：

**整理文件**

```
把 ~/Downloads/screenshots 下所有 .png 转成 WebP，质量约 80，
输出到同目录，扩展名改为 .webp。不要删除原 PNG。完成后列出转换了多少个文件。
```

**理解代码**

```
阅读当前项目，用要点说明 apps/ 与 packages/ 各自职责，
以及一次「用户发消息」从 UI 到引擎大致经过哪些模块。不要改任何文件。
```

**小改动**

```
在当前项目里给 README 增加一小节「本地开发」，内容根据仓库实际命令撰写。
只改 README，不要动其他文件。改完用 git diff 总结变更。
```

按 **Enter** 发送。你会看到状态从规划变为执行；过程细节默认较克制，完成后可展开活动列表。最终交付以 Markdown 或文件变更呈现。

### 运行中你可以做什么

| 情况 | 操作 |
|---|---|
| 方向错了 / 不想继续 | 点 **停止** |
| 弹出工具确认 | 核对参数后 **允许本次** 或 **拒绝** |
| Agent 追问缺信息 | 在对话里直接回答 |
| 目标写错了 | 编辑上一条用户消息并重试（见 [控制任务](./control)） |

输入 `/` 可浏览 **Skill**（网页搜索、浏览器等）。需要图片或本地文件作输入时，用附件入口添加。

# 设置

设置按分类组织。这里说明**会影响行为**的项；界面文案以当前版本为准。

改完设置后点各页的 **保存**，或标题栏 **保存并刷新**（先写入当前草稿，再从 Agent 重载）。外观与语言等本地偏好改完即生效。提供商连接使用连接区的「保存连接」。

改完模型与权限后，用一条小任务验证，再加大任务难度。

## 常规

### 工作模式

| 模式 | 效果 |
|---|---|
| 适用于编程 | 默认展示更多工具与轨迹细节 |
| 适用于日常工作 | 默认收起细节，优先结论与轻量进度 |

### 权限

| 选项 | 建议 |
|---|---|
| 允许运行终端命令 | 默认关；可信仓库且确实需要时再开 |
| 自动模式安全规则 | 默认开；勿在不了解风险时关闭 |

详见 [权限与审批](./permissions)。

### 任务预算

两层限制，防止单次或累计失控：

| 层 | 控制什么 |
|---|---|
| 单次执行 | 一次发言 / 恢复内的回合、工具次数、墙钟时间 |
| 任务寿命 | 整个任务跨续聊的累计上限 |

仅作用于**此后新建**的任务。触顶后的处理见 [控制任务](./control#预算用尽)。

### 工具执行策略

| 策略 | 特点 |
|---|---|
| 并行 | 多工具轮次可能更快 |
| 顺序 | 更易预测，便于逐步审批与调试 |

调试陌生流程时用顺序；确认稳定后再考虑并行。

### 出站代理

仅作用于 **Agent 引擎** 的外网请求（订阅登录 OAuth、模型 API、网页搜索等），**不会**自动读取 Windows/macOS「系统代理」。

| 选项 | 说明 |
|---|---|
| 启用出站代理 | 开启后 Node `fetch` 经填写的代理访问外网 |
| 代理地址 | 仅 **HTTP**：`http://127.0.0.1:7890`（Clash 的 HTTP / mixed 端口）。**不支持** `socks5://` |
| 不走代理 | 逗号分隔主机；默认绕过 `localhost` |
| 测试连接 | 保存设置后探测 `auth.x.ai`；失败时检查代理是否开启 |

在仅开启系统代理、未在此填写地址时，浏览器里的 OAuth 页面可能正常，但 xAI device-code 等 **Agent 侧请求** 仍会 `fetch failed`。TUN/全局 VPN 可替代本设置。

### 推理深度

也可在输入框切换。仅对支持 thinking / reasoning 的模型有意义。见 [如何写目标](./prompting#推理深度)。

### 关于与更新

桌面应用会从 [GitHub Releases](https://github.com/nullskymc/Aurevoy/releases) 检查新版本：

1. 启动后静默检查；有更新时 toast 提示  
2. 在本页可手动 **检查更新** / **下载并安装**  
3. 安装完成后应用会重启  

浏览器开发模式无此能力。维护说明见 [自动更新](/dev/auto-update)。

## 提供商与模型

1. 配置 Provider：类型、Base URL（可选）、API Key  
2. 启用要在主界面出现的模型  
3. 在对话输入区选择当前模型  

常见问题：「有 Key 但发不了」→ 模型未启用，或选中了未配置 Key 的 Provider。

> **DeepSeek 官方接入**：全量模型统一走官方 [Responses API](https://api-docs.deepseek.com/zh-cn/guides/responses_api)（`/responses`），不再使用旧式 Chat Completions。
> 个别模型在官方开放前调用会收到上游明确错误（如 `deepseek-v4-pro` 预计 2026 年 8 月初开放），不会降级到旧协议。
> 第三方网关（非官方主机）挂 DeepSeek 模型时仍按网关能力走 Chat Completions。

## 搜索

开启 **优先使用 API 原生搜索** 后，Aurevoy 会按当前实际协议自动尝试服务器搜索：

- Responses API（包括兼容端）使用托管 `web_search`；DeepSeek 官方 Responses 端点同样支持服务器搜索。
- Anthropic Messages API 使用服务器 Web Search。
- DeepSeek 官方模型全量走 Responses API，原生搜索使用服务器 `web_search`；上游拒绝时自动回落下方本地搜索后端。
- 上游不支持相应工具或协议时，自动回退原协议与下方配置的本地搜索后端。
- 对话过程只显示“正在搜索网页 / 已搜索网页”等工具状态；重启后从会话消息恢复，不展示 Provider 的内部搜索载荷。
- 服务器搜索可能由模型服务商单独计费；具体以服务商说明为准。

关闭该开关或发生自动回退时，Aurevoy `web_search` 函数工具使用这里配置的后端：

| 选项 | 说明 |
|---|---|
| DuckDuckGo Lite | 免费、无需 Key；可能被限流 |
| Tavily / SearXNG / 自定义 | 更稳定；需 Key 或自建地址 |

调研任务再依赖搜索；失败时检查限流与 API 配置，而不是无限重试同一提示。

## MCP 服务器

接入后外部工具出现在工具列表。设置页可新增、编辑、启停和删除服务器，并显示真实的连接状态、错误与工具数量。

- **本地 stdio**：填写命令、参数；按需补充工作目录和环境变量。
- **远程 Streamable HTTP**：填写服务 URL；需要认证时可加请求头。
- 只添加能去掉真实手工步骤的服务器  
- 连接失败应显示不可用  
- 高风险外部工具仍走审批逻辑  

保存后引擎会重载 MCP；单个服务器连不上不会阻断其它服务器或本地 Agent 启动。预置的推荐模板仍在完善，当前请按服务商文档手动填写连接信息。

## 本地数据与用量

- **本地数据**：本机存储相关管理（路径与操作以界面为准）  
- **Token 统计**：观察调用规模，便于控制成本  

卸载或迁移前，先确认是否需要备份本机数据目录。

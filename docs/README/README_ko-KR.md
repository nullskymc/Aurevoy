# Aurevoy

> *무엇을* 할지 말해주세요, *어떻게* 할지는 제게 맡기세요.
> 실제로 **일을 처리하는** 최초의 AI 동반자.

---

Aurevoy는 여러분의 컴퓨터에서 실행되는 개인 AI 에이전트입니다. 단순한 채팅 인터페이스를 넘어,
목표를 주면 나머지는 스스로 알아서 처리합니다: 리서치, 파일 작성, 웹 검색, 작업을 단계별로 수행합니다.

**마치 "제가 처리할게요"라고 말하는 사람이 바로 옆에 앉아 있는 것과 같습니다.**

---

## 할 수 있는 일

### 일상적인 작업, 그냥 요청하세요

```
"다운로드 폴더의 모든 PNG를 WebP로 변환해줘"
"React 19의 breaking changes를 조사하고 마이그레이션 체크리스트를 작성해줘"
"이 폴더의 코드를 읽고 README로 만들어줘"
```

Aurevoy가 작업을 분석하고 실행합니다. 어떻게 해야 하는지 설명할 필요가 없습니다.

### 코드 작성, 수정, 탐색

```
"이 프로젝트에 다크 모드를 추가해줘"
"src/utils에서 날짜 포맷팅 유틸리티를 찾아서 버그가 있는지 확인해줘"
"이 코드가 너무 느려요 — 병목 지점을 찾는 걸 도와주세요"
```

프로젝트 구조를 이해하고, 정확하게 수정하며, 문제를 찾아냅니다. 문제가 생기면 언제든 **실행 취소**할 수 있습니다 — 과거 메시지를 편집하거나, 대화를 분기시키거나, 컨텍스트를 압축하여 다시 시작할 수 있습니다.

### 리서치 및 문서 작성

```
"주요 React 상태 관리 라이브러리를 조사해서 장단점을 비교해줘"
"이 글을 한국어로 번역해주되, 기술 용어는 정확하게 유지해줘"
"이 회의 노트를 주간 보고서로 정리해줘"
```

웹에서 최신 정보를 검색하고, 자세한 내용을 위해 페이지를 가져오며, 필요한 형식으로 모든 것을 종합합니다.

### 이미지를 보고 이해하기

이미지나 파일을 대화 창에 끌어다 놓으세요. Aurevoy는 이미지를 감지하면 자동으로 비전 모델로 전환하여 스크린샷을 읽고, 다이어그램을 분석하며, 이미지 내용에 대한 질문에 답합니다.

### 사용자 선호도를 학습합니다

작업 방식을 알려주세요 — "저는 항상 pnpm을 사용합니다", "함수형 스타일을 선호합니다" — 그러면 기억합니다. 다음번에는 상기시키지 않아도 여러분의 규칙을 따릅니다.

## 작동 방식

목표를 입력하면 → Aurevoy가 작업 공간을 스카우트하여 컨텍스트를 파악합니다 → 계획을 세웁니다 → 단계별로 실행합니다:

- **파일을 읽어야 하나요?** 열어서 내용을 확인합니다.
- **무언가를 검색해야 하나요?** 웹에서 최신 정보를 검색합니다.
- **코드를 작성해야 하나요?** 관련 없는 부분은 건드리지 않고 정확하게 수정합니다.
- **여러분의 입력이 필요하나요?** 잠시 멈추고, 질문한 후, 승인을 기다렸다가 계속 진행합니다.

모든 단계를 볼 수 있습니다. 방향이 마음에 들지 않나요? 언제든지 중단하고 수정한 후 다시 시작할 수 있습니다. 과거 메시지를 편집하여 그 시점부터 다시 생성하거나, 새 분기 스레드에서 다른 방향을 탐색할 수도 있습니다.

## 여러분의 데이터, 여러분의 규칙

- **모든 것이 로컬에서 실행됩니다.** 데이터가 여러분의 컴퓨터를 떠나지 않습니다.
- 여러분의 API 키를 사용하고 원하는 모델을 선택합니다.
- 코드는 오픈 소스입니다 — 항상 정확히 무엇을 하고 있는지 확인할 수 있습니다.

## 시작하기

### 1. 다운로드

[Releases](../../releases)에서 최신 DMG를 다운로드하여 Applications 폴더로 드래그하세요.

### 2. 모델 구성

Aurevoy를 열고 설정에서 모델 정보를 입력하세요:

```
제공자: OpenAI (또는 호환 API)
Base URL: https://api.openai.com/v1
모델: gpt-4o-mini
API Key: sk-xxxx
```

OpenAI, DeepSeek, Ollama 및 모든 OpenAI 호환 엔드포인트에서 작동합니다. 여러분의 키를 사용하세요 — 추가 요금은 없습니다.

### 3. 대화 시작

입력창에서 Aurevoy에게 필요한 것을 말하세요. 사람과 대화하듯이 하면 됩니다.

```
/  사용 가능한 스킬 확인 (web-search, browser 등)
```

## 기여하기

Aurevoy는 오픈 소스입니다. 기여를 환영합니다.

```bash
# 필수 환경: Node.js >= 20, Rust (stable), macOS
git clone https://github.com/nullskymc/Aurevoy.git
cd Aurevoy
npm install
npm run dev          # 개발 모드 시작
npm run typecheck    # 타입 검사
npm run build        # 프로덕션 빌드
```

자세한 내용은 [AGENTS.md](../AGENTS.md) 및 [docs/](docs/)를 참조하세요.

## 기술 스택

| 계층 | 기술 |
|---|---|
| 데스크톱 앱 | Tauri 2 + React + TypeScript |
| Agent 엔진 | Node.js + Fastify + SQLite |
| 통신 방식 | 로컬 HTTP + SSE 스트리밍 |
| 도구 확장 | 내장 도구 + MCP 프로토콜 (외부 도구 서버 연결) |
| Skill 시스템 | 슬래시 명령으로 활성화, 사용자 정의 스킬 지원 |

자세한 내용은 [docs/ARCHITECTURE.md](ARCHITECTURE.md)를 참조하세요.

## 탑재된 기능

- 자율 계획 및 병렬 도구 실행
- 파일 읽기/쓰기/검색/복사/이동/삭제, diff 기반 정확한 수정
- 웹 검색 및 페이지 가져오기 (SSRF 방어 포함)
- 장기 기억 (시간이 지남에 따라 사용자 선호도 학습)
- 다중 턴 대화, 편집 및 재시도, 분기 스레드, 컨텍스트 압축
- 멀티모달: 이미지/파일 드래그 앤 드롭, 비전 모델 지원
- 프로젝트 워크스페이스 (대화 프로젝트별 정리)
- Skill 시스템 (슬래시 명령, 사용자 정의 스킬)
- macOS 네이티브 데스크톱 앱

다음 예정: 지식 베이스 / RAG, Agent 평가 프레임워크, 릴리스 완성도 향상. 자세한 내용은 [ROADMAP](ROADMAP.md)을 참조하세요.

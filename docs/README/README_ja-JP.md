# Aurevoy

> *何を* したいか伝えてください — *どうやるか* は私たちにお任せ。
> あなたの初めての、実際に **仕事をやってのける** AI パートナー。

---

Aurevoy はあなたのコンピュータ上で動作するパーソナル AI エージェントです。単なるチャットインターフェースではありません。
ゴールを伝えると、あとはすべて自動で進めます：リサーチ、ファイル作成、ウェブ検索、タスクの段階的な遂行。

**まるで「任せてください」と言う人が隣に座っているかのようです。**

---

## できること

### 日常のタスク、お願いするだけ

```
"ダウンロードフォルダの全 PNG を WebP に変換して"
"React 19 の breaking changes を調べて、移行チェックリストを作成して"
"このフォルダのコードを読んで README にまとめて"
```

Aurevoy がタスクを分解して実行します。やり方を説明する必要はありません。

### コードの作成、編集、探索

```
"このプロジェクトにダークモードを追加して"
"src/utils で日付フォーマットのユーティリティを探して、バグがないか確認して"
"このコードは遅すぎます — ボトルネックを見つけてください"
```

プロジェクト構造を理解し、正確に編集し、問題を特定します。何か問題が起きても、いつでも **元に戻せます** — 過去のメッセージを編集したり、会話を分岐させたり、コンテキストを圧縮してやり直せます。

### リサーチ & 文章作成

```
"主要な React 状態管理ライブラリを調査して、長所と短所を比較してください"
"この記事を日本語に翻訳してください。技術用語は正確に保ってください"
"このミーティングノートを週次レポートにまとめてください"
```

ウェブで最新情報を検索し、詳細をページから取得し、必要な形式にすべてをまとめます。

### 画像を見て理解する

画像やファイルを会話ウィンドウにドラッグ＆ドロップしてください。Aurevoy は画像を検出すると自動的にビジョンモデルに切り替え、スクリーンショットを読み取り、図表を分析し、画像の内容について回答します。

### あなたの好みを学習します

作業スタイルを伝えてください — 「いつも pnpm を使います」「関数型スタイルが好みです」 — すると記憶します。次回からは言われなくてもあなたの流儀に従います。

## 仕組み

ゴールを入力 → Aurevoy がワークスペースを偵察してコンテキストを把握 → 計画を立案 → ステップごとに実行：

- **ファイルを読む必要がありますか？** 開いて内容を確認します。
- **何かを調べる必要がありますか？** ウェブで最新情報を検索します。
- **コードを書く必要がありますか？** 無関係な部分に触れずに正確に編集します。
- **あなたの入力が必要ですか？** 一時停止して確認を求め、承認を待ってから続行します。

すべてのステップを確認できます。方向性が気に入らない？いつでも中断して修正し、再開できます。過去のメッセージを編集してその時点から再生成したり、新しい分岐スレッドで別の方向を探索することもできます。

## あなたのデータ、あなたのルール

- **すべてローカルで実行されます。** データがあなたのマシンを離れることはありません。
- ご自身の API キーを使用し、好きなモデルを選択できます。
- コードはオープンソースです — 常に何をしているかを正確に確認できます。

## はじめに

### 1. ダウンロード

[Releases](../../releases) から最新の DMG をダウンロードし、Applications フォルダにドラッグしてください。

### 2. モデルを設定

Aurevoy を開き、設定でモデル情報を入力してください：

```
プロバイダー: OpenAI (または互換 API)
Base URL: https://api.openai.com/v1
モデル: gpt-4o-mini
API Key: sk-xxxx
```

OpenAI、DeepSeek、Ollama など、OpenAI 互換のエンドポイントで動作します。ご自身のキーをお使いください — 追加料金はありません。

### 3. 会話を始める

入力欄で Aurevoy に必要なことを伝えてください。人に話すように気軽にお願いしてください。

```
/ 利用可能なスキルを確認 (web-search、browser など)
```

## 開発に参加する

Aurevoy はオープンソースです。コントリビューションを歓迎します。

```bash
# 前提環境: Node.js >= 20, Rust (stable), macOS
git clone https://github.com/nullskymc/Aurevoy.git
cd Aurevoy
npm install
npm run dev          # 開発モードを開始
npm run typecheck    # 型チェック
npm run build        # プロダクションビルド
```

詳細は [AGENTS.md](../../AGENTS.md) と [docs/](../) を参照してください。

## 技術スタック

| レイヤー | 技術 |
|---|---|
| デスクトップアプリ | Tauri 2 + React + TypeScript |
| Agent エンジン | Node.js + Fastify + SQLite |
| 通信方式 | ローカル HTTP + SSE ストリーミング |
| ツール拡張 | 内蔵ツール + MCP プロトコル (外部ツールサーバー接続) |
| スキルシステム | スラッシュコマンドでアクティブ化、カスタムスキル対応 |

詳細は [docs/ARCHITECTURE.md](../ARCHITECTURE.md) を参照してください。

## 搭載機能

- 自律計画 & 並行ツール実行
- ファイル読み取り/書き込み/検索/コピー/移動/削除、diff ベースの正確な編集
- ウェブ検索 & ページ取得（SSRF 防御含む）
- 長期記憶 (時間とともに好みを学習)
- マルチターン会話、編集と再試行、スレッド分岐、コンテキスト圧縮
- マルチモーダル: 画像/ファイルのドラッグ＆ドロップ、ビジョンモデル対応
- プロジェクトワークスペース（会話のプロジェクト別整理）
- スキルシステム (スラッシュコマンド、カスタムスキル)
- macOS ネイティブデスクトップアプリ

次回予定: ナレッジベース/RAG、Agent 評価フレームワーク、リリース品質の向上。詳細は [ROADMAP](../ROADMAP.md) を参照してください。

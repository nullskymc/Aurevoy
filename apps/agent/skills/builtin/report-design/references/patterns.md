# 报告类型模式（按需阅读）

默认结构见主 SKILL。仅在对应类型需要更细大纲时阅读。

## 技术评估

1. 结论先行：推荐方案、评分、成本/周期  
2. 背景和评估范围  
3. 候选方案概览  
4. 评分矩阵和关键指标  
5. 风险和缓解  
6. 推荐路径和下一步  

组件：`stat-cards`、`card-grid`、表格+`score-cell`、`callout`、`decision`

## 调研报告

1. 调研问题和范围  
2. 来源和样本量  
3. 关键发现  
4. 市场/竞品/方案对比  
5. 机会、风险、建议  

组件：`findings`、`card-grid`、`bar-chart`（少用）、`decision`

## 项目计划

1. 目标和交付物  
2. 里程碑  
3. 任务分解  
4. 资源和风险  
5. 决策点  

组件：`timeline`、`steps`（少用）、`progress`（少用）、`callout`、表格

## 会议纪要

1. 主题、时间、参与者  
2. 结论和决定  
3. 讨论摘要  
4. 行动项  
5. 待确认问题  

组件：`stat-cards`、`findings`、`tag`（少用）、`accordion`（少用）

## 设计方案

1. 设计目标  
2. 用户/业务约束  
3. 方案说明  
4. 取舍分析  
5. 实施路径  
6. 验收标准  

组件：`card-grid`、`pros-cons`（少用）、`steps`（少用）、`decision`
